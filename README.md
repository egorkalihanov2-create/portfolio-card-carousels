# Portfolio card carousels

Two responsive presentations of the same Figma project cards:

- a perspective card stack controlled by wheel, swipe, keyboard arrows, and dots;
- a horizontal carousel controlled by drag, wheel, keyboard arrows, buttons, and dots.

Clicking any card opens its expanded project view over a dimmed background. Close it with the round close button, the backdrop, or `Escape`.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
